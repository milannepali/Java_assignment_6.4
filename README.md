# Assignment 6.4 – Notebook Application

## About the Project

I created a simple notebook application using JavaFX, Scene Builder, and FXML. Users can write notes, give them titles, and add them to a list of saved notes.

## Completed Requirements

1. **User Interface:** I created the interface using Scene Builder and FXML. It includes a TextField, TextAreas, an Add button, and a VBox layout.

2. **FXML:** The application loads the FXML file and displays the interface correctly.

3. **Model:** I created Note.java to store the title and content, and Notebook.java to store multiple notes.

4. **Controller:** I created NoteController.java to handle the Add button and manage the notes.

5. **Saving Notes:** Users can add notes, and the saved notes appear below the input fields. I tested adding multiple notes, and everything worked correctly.
